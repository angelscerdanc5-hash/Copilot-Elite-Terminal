# Copilot+ Elite Terminal Suite 💎🚀

¡Transforma tu terminal de Windows en una interfaz inteligente, futurista y de alto rendimiento! Esta suite unifica **PowerShell 7** y **CMD** bajo una identidad estética de IA, con animaciones de inicio, telemetría en tiempo real y un diseño ultra-premium.

## ✨ Características
- **Diseño Glassmorphism**: Transparencia acrílica al 65% con un esquema de colores "Elite" (Obsidiana y Neón).
- **Animaciones de Inicio**: Secuencia de carga técnica y efecto de escritura tipo IA (Typewriter con decodificación).
- **Telemetría en Tiempo Real**: Monitor de RAM y estado del núcleo al iniciar.
- **Identidad Inteligente**: Detección automática de Hardware (Marca/Modelo), Sistema Operativo y Usuario.
- **Unificación Total**: Misma experiencia visual tanto en PowerShell como en el Símbolo del Sistema (CMD).

## 🚀 Instalación Rápida
1. Descarga este repositorio.
2. Abre PowerShell como Administrador.
3. Ejecuta el instalador:
   ```powershell
   ./setup.ps1
   ```

## 🛠️ Contenido
- `setup.ps1`: Script de automatización que configura los perfiles y el diseño de la terminal.
- `PowerShell_Profile.ps1`: Configura el prompt, animaciones y herramientas de PowerShell.
- `Copilot_CMD.cmd`: Script de inicio para CMD con colores ANSI y animaciones.
- `Terminal_Settings.json`: Archivo de configuración para Windows Terminal (Cian Neón + 45px Padding).

## 📝 Notas de Ingeniería
Desarrollado con estándares de Microsoft Engineering para asegurar compatibilidad con **PowerShell 7** y las últimas versiones de **Windows Terminal**.
